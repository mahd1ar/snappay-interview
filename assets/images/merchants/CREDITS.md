# Merchant photos — credits

store card show the same shop. Same processing as `../stores/` (crop, saturation +12%, light contrast curve, WebP).
The shops are real businesses used only as generic storefront imagery for the fictitious sample merchants; replace them
with the sample data before launch. CC BY / CC BY-SA require this attribution; adapted CC BY-SA images keep that licence.
